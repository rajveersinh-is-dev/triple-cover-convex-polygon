The triple-covering number of a convex n-gon: a gap-weight certificate lower bound for all n, exact values (certified) for n<=14, and a solved boundary-edge sub-problem

## Overview

`triple-cover-convex-polygon` is a systems-level tool featuring lexical analysis, parsing, and execution pipelines designed for efficiency and correctness.

## Features

- Modular tokenizer and parser pipeline.
- Comprehensive test suite for language grammar and runtime operations.
- Performance benchmarks evaluating throughput and memory efficiency.

## Getting Started

```bash
git clone https://github.com/rajveersinh-is-dev/triple-cover-convex-polygon.git
cd triple-cover-convex-polygon
pip install -r requirements.txt
```

Run tests:

```bash
pytest tests/
```
